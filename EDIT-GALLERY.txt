تعديل الجاليري بنفسك - شرح عملي خطوة بخطوة
============================================

كل التصميمات متخزنة كقايمة جوه ملف main.js. كل تصميم عبارة عن سطر
شكلهم كده (ممكن تلاقي الحروف العربي ظاهرة كرموز \u0627 - ده طبيعي،
وعادي تكتب عربي براحتك والموقع هيفهمه):

  { number: 91, name: "مونوجرام حروفكم", colors: "عنابي وبيج",
    photo: n91_monogram_default, file: "veloura-91-monogram.jpg", alt: "وصف الصورة" },

معنى كل جزء:
- number : رقم التصميم اللي بيظهر للعميل (امسحه لو عاوز تصميم بدون رقم)
- name   : اسم التصميم
- colors : ألوان الهوديين
- photo  : ملف الصورة جوه مجلد assets
- file   : اسم الملف اللي بينزل للعميل لما يدوس "حمّل صورة التصميم"
- alt    : وصف الصورة (للقراءة الصوتية وSEO)

---------------------------------------------------------
مثال عملي كامل: إضافة تصميم جديد رقم 92
---------------------------------------------------------
1. حط صورة التصميم الجديدة جوه مجلد assets، مثلا باسم:
   assets/new-92.jpg

2. افتح main.js بأي محرر نصوص (Notepad أو VS Code) وابحث عن:
   veloura-91-monogram.jpg
   (ده آخر تصميم حالي، عشان تحط الجديد بعده)

3. هتلاقي السطر منتهي بـ },
   بعده على طول ضيف السطر ده (بنفس الشكل بالظبط):

    { number: 92, name: "الاسم اللي يعجبك", colors: "أسود وأبيض", photo: "./assets/new-92.jpg", file: "veloura-92-new.jpg", alt: "هوديين أسود وأبيض عليهم التصميم الجديد" },

4. احفظ الملف وارفعه مكان القديم على الاستضافة. التصميم الجديد
   هيظهر في آخر الجاليري بأزراره (تحميل + ماسنجر) أوتوماتيك.

---------------------------------------------------------
تعديل تصميم موجود:
---------------------------------------------------------
1. ابحث في main.js عن اسم ملف التصميم (من ASSETS-MAP.txt)، مثلا:
   veloura-40-yinyang-cats.jpg
2. غيّر name أو colors زي ما تحب (تقدر تكتب عربي عادي مكان الرموز).

حذف تصميم:
- امسح سطره بالكامل من { لحد }, وامسح صورته من assets لو حابب.

استبدال صورة تصميم بس:
- حط الصورة الجديدة مكان القديمة في assets بنفس الاسم بالظبط
  (شوف ASSETS-MAP.txt تعرف كل ملف بتاع أنهي تصميم).

ملحوظة مهمة: خد نسخة احتياطية من main.js قبل أي تعديل. لو حاجة
اتلخبطت، ارجع للنسخة الاحتياطية أو اطلب من Instinct يظبطهالك.
