موقع فيلورا VELOURA - نسخة كاملة للاستضافة الذاتية
====================================================

المحتوى:
- index.html, main.css, main.js : ملفات الموقع
- assets/ : صور التصميمات (40 تصميم: 20 مرقّم + 20 كلاسيك) + الخطوط
- collage.jpg : صورة معاينة اللينك
- ASSETS-MAP.txt : خريطة توضح كل صورة في assets بتاعة أنهي تصميم
- EDIT-GALLERY.txt : شرح تعديل الجاليري بنفسك (مع مثال جاهز خطوة بخطوة)

التشغيل:
1. ارفع كل الملفات والمجلدات زي ما هي بالظبط على أي استضافة static
   (مثل cPanel أو Netlify أو Vercel أو GitHub Pages).
2. مهم تحافظ على نفس الهيكل: index.html و main.js و main.css جنب بعض،
   ومجلد assets جنبهم.
3. الموقع هيشتغل فورًا بدون أي إعدادات.

صورة معاينة اللينك (واتساب/ماسنجر):
- Meta tags جاهزة في index.html (عنوان + وصف + صورة).
- بعد رفع الموقع على الدومين بتاعك، عدّل سطر og:image و twitter:image
  وحط لينك الصورة الكامل (مثال: https://www.yourdomain.com/collage.jpg)
  لأن برامج المعاينة بتقبل اللينك الكامل بس. في كومنت فوق السطر بيوضح ده.

التعديل:
- استبدال صورة تصميم: حط الصورة الجديدة مكان القديمة في assets بنفس الاسم
  (شوف ASSETS-MAP.txt عشان تعرف كل ملف بتاع أنهي تصميم).
- إضافة أو تعديل تصميم في الجاليري: شوف EDIT-GALLERY.txt فيه مثال
  عملي كامل خطوة بخطوة.
- ولو حبيت أي تعديل أكبر، اطلبه من Instinct وأسهل وأأمن.

ملحوظة: النسخة دي مطابقة للموقع اللايف وقت تصديرها (20 تصميم مرقّم + 20 كلاسيك).
